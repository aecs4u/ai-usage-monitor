# Security Policy

## Supported Versions

We support the latest released version of AI Usage Monitor. Please update to
current releases before reporting issues.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please report it
privately by emailing maciek@roboblog.eu.

Please include:
- A clear description of the issue
- Steps to reproduce (proof of concept if available)
- Potential impact
- Any suggested mitigation

We will acknowledge receipt within 72 hours and provide a timeline for a fix
once the issue is confirmed.
