## 🛠️ Troubleshooting

### Release workflow fails
- Check PYPI_API_TOKEN secret is set
- Verify token has correct scope
- Ensure version doesn't exist on PyPI

### Social media low engagement
- Post during peak hours (9-11am, 1-3pm ET)
- Add visuals (screenshots, GIFs)
- Engage with comments immediately
- Cross-promote across platforms

### No community contributions
- Ensure good first issues are well-documented
- Respond to questions quickly
- Thank all contributors
- Make contributing easy (clear CONTRIBUTING.md)

### Low PyPI downloads
- Check SEO keywords in description
- Add to more awesome lists
- Reach out to relevant communities
- Create more content (blogs, videos)
